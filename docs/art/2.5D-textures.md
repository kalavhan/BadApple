# Hotel material sources

All three assets were produced with the built-in imagegen tool and copied into the project:

- `Assets/Resources/Art/Materials/haunted_wall.png`: repeating wall material.
- `Assets/Resources/Art/Directions/gun_turret.png`: zombie/Pistol Revenant, four tiers × eight static directions.
- `Assets/Resources/Art/Directions/sniper_nest.png`: Ghost Marksman, four tiers × eight static directions.

The delivered direction atlases are 1774 × 887 pixels; runtime slicing uses their actual dimensions. The requested dimensions in the prompts below describe the generation request, not the delivered file size. No tower animation was added.

## Ghost static facing atlas

Built-in imagegen, October 4, 2026, using the four existing tower tier sprites as references. Eight columns (E, NE, N, NW, W, SW, S, SE); four tier rows. No animation or AutoSprite usage.

Prompt: Create a production sprite atlas for Bad Apple Hotel. These FOUR reference images are the EXACT four upgrade tiers of the same Ghost Marksman tower. Preserve each row's distinct skull/mask, ragged purple cloak, rifle and dark comic ink rendering. Draw static aiming poses, NOT animation. Output transparent background, 2048 pixels wide by 1024 high. Layout perfectly regular grid of EIGHT columns and FOUR rows, no gutters: cells 256x256. Row 1 matches reference 1 little ghost with ivory long mask and short gun; row 2 matches reference 2 skull ghost long scope rifle on tripod; row 3 matches reference 3 skull revenant in wide brim hat with long rifle; row 4 matches reference 4 grand hooded phantom in ivory long mask with giant scope rifle. Each row shows eight DISTINCT views of its same character facing and aiming in these screen directions left to right: E (right), NE (up-right), N (away/up, back visible), NW (up-left), W (left), SW (down-left), S (toward camera/down, face visible), SE (down-right). Elevated isometric camera at 45 degrees, consistent scale and elevation throughout. Each sprite centered horizontally in its cell, robe bottom/feet centered at x128 y232 inside each cell; full figure and entire weapon stay inside their own cell with 12px margins. Characters turn their bodies with their weapons: north-facing views show back of hood or hat, never a face. NO spinning a flat drawing, NO repeated front views. Consistent feet alignment. No shadows outside sprites, no text, labels, grid lines, borders or extra characters.

## Zombie static facing atlas

Built-in imagegen, October 4, 2026, using the four existing tower tier sprites as references. Eight columns (E, NE, N, NW, W, SW, S, SE); four tier rows. No animation or AutoSprite usage.

Prompt: Create a production sprite atlas for Bad Apple Hotel. These FOUR reference images are the EXACT four upgrade tiers of the same zombie soldier tower. Preserve each row's distinct character design, purple ragged uniform, skull face, helmet, gun and dark comic ink rendering. Draw static aiming poses, NOT animation. Output transparent background, exactly 2048 pixels wide by 1024 high. Layout is a perfectly regular grid of EIGHT columns and FOUR rows, no gutters: every cell exactly 256x256. Row 1 matches reference 1 pistol; row 2 matches reference 2 rifle; row 3 matches reference 3 shotgun; row 4 matches reference 4 machine gun ammo belts. Each row shows eight DISTINCT views of its same character facing and aiming in these screen directions left to right: E (right), NE (up-right), N (away/up, back visible), NW (up-left), W (left), SW (down-left), S (toward camera/down, face visible), SE (down-right). Elevated isometric camera, view character from above at 45 degrees, consistent scale and elevation throughout. Each sprite centered horizontally in its cell, feet centered at x128 y232 inside each cell; full body and entire weapon stay inside their own cell with 12px margins. Characters must turn their bodies and heads with guns, back views have back of helmet, NO spinning a flat drawing, NO repeated front views. Consistent feet alignment. No shadows outside sprites, no text, labels, grid lines, borders or extra characters.

`Assets/Resources/Art/Materials/haunted_wall.png` was generated with the built-in imagegen tool on October 4, 2026. It is imported with point filtering and repeat wrapping for the 3D hotel walls. No AutoSprite credits or Tripo models were used.

Prompt:

Use case: stylized-concept. Asset type: seamless game wall texture, diffuse/albedo, square 1024x1024, front-on flat orthographic surface with absolutely no perspective. Primary request: Tim Burton-style darkly humorous haunted hotel wallpaper and aged plaster rendered as deliberate crisp pixel art. Repeating thin crooked charcoal and muted purple vertical stripes, tiny subtly grinning skull-like damask motifs and suspicious little eye shapes within decorative faded teal flourishes; worn plaster chips and gentle grunge, desaturated bone highlights. Mood: shabby whimsical macabre hotel, charming and eerie, restrained enough for repeated walls behind characters. Seamlessly tileable left/right AND top/bottom: pattern carries through all four borders. Uniform flat ambient illumination, no directional lighting, no baked shadows or glow, no vignette. Fill entire image with the material. Pixel-art texture, visible clean pixel clusters, limited palette, no antialiasing or painted brush strokes. No room scene, no furniture, no characters, no border, no text, no watermark.
